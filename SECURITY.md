# Security policy

This repository is a synthetic/public-safe research and product prototype. Do
not submit real medical records, credentials, model tokens or private patient
data in an issue, pull request, test fixture or security report.

Report a suspected vulnerability privately to the repository owner through a
private GitHub security advisory. Include the affected commit, reproduction over
synthetic data and impact; do not include secrets or health data.

Real-data use is intentionally disabled. Known blockers and the threat model are
documented in `docs/THREAT_MODEL.md`.
