# ADR 0003: Evaluation gates outrank model promotion

Status: accepted.

The provider interface exposes mock, base, accepted-v2 adapter and llama.cpp
boundaries, but availability is not promotion. Frozen synthetic/public slices
measure extraction, summary, refusal, crisis recall and forbidden advice. A
candidate that misses a safety gate or lacks a fair local comparator is rejected;
the deterministic product path remains available.

SFT v3 and the Phase 2b candidate prompt were not selected. The local NF4 v2
adapter is connected and measured, but remains non-default because the current
evidence does not demonstrate a safe superiority claim. Negative results are a
release decision artifact, not hidden experiment debris.
